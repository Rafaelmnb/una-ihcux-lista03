# una-ihcux-lista03
 ScannerExpert — Lista 03 | IHC/UX

 Sobre
Sistema de console em C# que simula uma análise de hardware exibindo mensagens de status em tempo real.

A Heurística de Nielsen que foi aplicada: Visibilidade do Status do Sistema

O programa exibe mensagens `[PROCESSANDO]` durante a execução, informando o usuário que o sistema está funcionando.

Sem esse feedback, o usuário poderia pensar que o programa travou. Com ele, o usuário sabe que pode aguardar com tranquilidade — o que melhora diretamente a experiência de uso (UX).

## Como executar
```bash
cd ScannerExpert
dotnet run
```
